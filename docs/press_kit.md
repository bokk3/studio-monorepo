## 1. Fact Sheet

*   **Studio Name:** Tachyon Studios (Tachyon Interactive)
*   **Founded:** 2026
*   **Operating Model:** AI-Assisted, Human-Directed Independent Game Studio
*   **Official Website:** [https://web-gateway.truyensboris.workers.dev](https://web-gateway.truyensboris.workers.dev)
*   **Monorepo Source:** [https://github.com/bokk3/studio-monorepo](https://github.com/bokk3/studio-monorepo)
*   **Core Technology Stack:**
    *   *Engines:* Godot Engine 4.7 (MIT), Three.js (MIT), Unreal Engine 5
    *   *Networking:* Cloudflare Edge Workers, WebRTC Peer-to-Peer DataChannels, Embedded TCP/WebSocket Server
    *   *Asset Pipeline:* Autodesk Fusion 360 (CAD) &rarr; Headless Blender Automation &rarr; Godot/UE5
    *   *Backend:* Supabase (PostgreSQL, Single Pilot Clearance Profile)
*   **Current Projects:**
    1. **Astro-Smash: Arena** (Web F2P, 3v3 Aerodynamic Sports Brawler)
    2. **Orbit Runner: Gyro Dash** (Mobile F2P, 6-DOF Vertical Gyro Flight)
    3. **Vanguard: The Outer War** (AAA Premium, 32v32 Cinematic Fleet Combat)

## 2. Studio Boilerplate

> *"Tachyon Studios is a next-generation game development studio engineered from the ground up to eliminate server hosting bills, physical controller barriers, and manual asset bottlenecks. By combining human creative direction with autonomous AI department pipelines, Tachyon pairs open-source engines (Godot 4, Three.js) with serverless edge computing on Cloudflare and peer-to-peer WebRTC data channels. The studio delivers high-fidelity, AA/AAA multiplayer titles with sub-3ms local latency, zero server operating costs, and mobile smartphone companion controls."*
